# 空名之子

> 一個習慣讓世界看見自己的人，最後必須學會停止替別人決定誰值得被看見。

《空名之子》是一部以**都市異常、人物悲劇與群像救援**為核心的長篇故事企劃。故事從舞台、工作、家庭與城市生活出發，逐步揭開能力、監控、代答網路與「原初未名」之間的牽連；異常不會取代人物的選擇，能力也不能抵銷責任。

## 故事簡介

林晏珩是曜環成員，出道約兩年半。他渴望被需要、被優先選擇，也害怕被替代。當一次換角與長期累積的不滿把他推向不可逆的選擇，他清醒地殺死了郁承璟；不久後，真正與他共同生活的人——周聽瀾——在事故中死亡。

之後，林想救下周曾保護的孩子秦小禾，卻逐漸發現自己所在的城市，正把人的聲音、形象與選擇交給可以永遠代答的網路。當他越過能力邊界、在失控中實際受傷，整個人形變成危險而漂亮的半透明膜帶。回到人形並不代表一切復原：他必須面對傷者、失去的人、自己的罪，以及仍然存在的力量。

## 重要設定

### 林晏珩與原初未名

林晏珩不是林奕辰的轉世、附身、複製品或復活者。他是自然出生、擁有完整人類身體與人生的人；「原初未名」是分類、命名與固定形態之前的根本可能性，並不是一位古神或另一個人格。

原初未名能恢復被忽略、排除或尚未固定的可能性，但不能製造真正不可能之事。它的影響不會替林晏珩做選擇，也不會替他取消殺人、傷害與刑責。

### 能力邊界

林晏珩能在辨認並指定的局部位置建立有限作用，例如托持、拉回、偏轉、減重與局部現象爆裂。他的能力依賴位置與結構理解；遮擋、移動、未知內部空間與鬆散的作用邊界都會提高錯置風險。

他沒有讀心、透視、憑姓名全球鎖定、隔海攻擊未知目標等能力，也沒有以壽命、記憶或血量支付的固定「魔力槽」。真正睡眠可以修復他自己的傷勢，但不能治療別人、復活死者、抹去創傷或免除責任。

失控時，他的全身會化為冷白、淡藍與薄虹光交錯的半透明長膜帶及不等膜瓣。這不是可隨時裝備的變身，也沒有第二人格；它是一次由越界、實際受傷與死亡恐懼共同造成的非人反應。

## 核心人物

- **林晏珩**：曜環成員。從爭取所有注視，走向承認他人有拒絕、不原諒與自行選擇的權利。
- **周聽瀾**：林的伴侶與社區聲景工作者。她有自己的工作、生活與選擇；她確實死亡，不以仿聲或複製品替代。
- **秦小禾**：九歲的孩子。她不是被救援者道德化的象徵，而是有喜惡、恐懼與拒絕權的活人。
- **何迴**：零序署約聘紀錄員。她可以害怕林、拒絕林，也可以在可行範圍內參與救援；私人信任不會因共同冒險自動恢復。

## 寫作原則

1. **生活先於設定**：工作、吃飯、交通、薪資、疲勞與普通笑話，都是異常造成損失時的重量。
2. **限知而不偷讀**：人物只能使用當下看見、聽見、推測或已核實的資訊。
3. **能力不取代行動**：異常作用不能跳過位置、設備、專業、協作與失敗的後果。
4. **救援不抵銷責任**：林想救小禾，不代表他因此成為英雄，也不會抵銷他對郁承璟與其他人的責任。
5. **傷害留下痕跡**：自癒只屬於林本人；周不回來，其他傷者的身體與心理後果仍然存在。
6. **結局不是沒收力量**：林保有能力，卻選擇接受監督、刑責與他人不原諒，繼續活著。
